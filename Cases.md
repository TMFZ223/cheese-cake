# Автоматизация тест-кейсов для интернет-магазина десертов https://cheese-cake.ru/

Для отчётности будет использоваться библиотека allure.

   ### 1 Позитивный тест на логин

** Логин с данными, которые использовались при создании учётной записи покупателя

** Предусловие: открыть страницу https://cheese-cake.ru/

Постусловие: Очистить куки


Шаги:
   - Перейти по ссылке войти

   - Кликнуть на элемент "Войти по логину"


   - Заполнить поле логин

Тестовые данные: ваш логин, который использовался при создании аккаунта покупателя

   - Заполнить поле пароль

Тестовые данные: ваш пароль, который использовался при создании аккаунта покупателя

   - Нажать на кнопку "Войти"

Ожидаемый результат: На странице присутствует элемент, где написано имя покупателя.
